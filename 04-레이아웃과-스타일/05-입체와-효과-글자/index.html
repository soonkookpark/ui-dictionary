01

3D 입체 3D extrude

글자를 한쪽으로 쭉 밀어 올린 듯한 두께가 있는 스타일입니다. 3D 프로그램이 없어도 같은 색 그림자를 1px 씩 어긋나게 열 겹 이상 쌓으면 만들 수 있습니다. 익스트루드는 "밀어 늘린다"는 뜻입니다.

언제 쓰나게임·이벤트 배너, 어린이 콘텐츠, 포스터의 큰 제목, 숫자 카운트 연출.

AI에게 이렇게3D 입체 스타일로 보라 배경에 노란 TYPE 글자를 만들고 분홍색 text-shadow 를 1px 씩 12겹 쌓아 두께를 만든 뒤 바닥 그림자를 한 겹 더 넣어줘

20년차 메모text-shadow 를 12겹 이상 쌓으면 글자가 많은 화면에서 그리기 비용이 커져 스크롤이 버벅일 수 있습니다. 제목 한두 줄에만 쓰세요. 두께가 한쪽으로만 늘어나는 단순한 방식이라 글자 크기가 달라지면 그림자 길이도 같이 계산해야 하고, 모바일에서는 길이를 줄여 주세요.

02

인플레이트 3D Inflated 3D

글자가 풍선에 바람을 넣은 듯 통통하고 윤이 나는 3D 스타일입니다. 굵은 둥근 글꼴에 밝은 윗면과 어두운 아랫면을 얹어 부피를 만듭니다. 풍선 글자, 영어로 balloon type이라고도 합니다.

언제 쓰나아이·친구·파티 앱의 대표 제목, 이벤트 배너, 스티커·캐릭터 느낌의 브랜드.

AI에게 이렇게인플레이트 3D 스타일로 분홍색 풍선처럼 통통한 Type 글자를 만들어줘. 위는 밝고 아래는 진한 그라데이션과 바닥 그림자를 넣어줘

20년차 메모진짜 3D 렌더 이미지로 만들면 글자가 그림이 되어 번역·검색·화면 읽기가 모두 막힙니다. 제목 한두 단어만 이미지로 쓰고 대체 텍스트를 꼭 달거나, 이 데모처럼 CSS 로 흉내 내세요. 파스텔 분홍 위의 분홍 글자는 대비가 낮으니 작은 글자에는 쓰지 말고 큰 제목에만 쓰세요.

03

엠보싱 Emboss

종이를 눌러 글자가 솟아오르거나 눌린 것처럼 보이게 하는 스타일입니다. 배경과 거의 같은 색에 왼쪽 위는 밝은 그림자, 오른쪽 아래는 어두운 그림자를 주면 만들어집니다. 눌린 쪽은 디보싱(debossing)이라고 합니다.

언제 쓰나고급 명함·카드 느낌의 제품 소개, 뉴모피즘 계열 화면의 제목, 질감을 보여주는 브랜드 페이지.

AI에게 이렇게엠보싱 스타일로 연한 청회색 배경과 같은 색의 굵은 Type 글자를 왼쪽 위 흰 그림자, 오른쪽 아래 어두운 그림자로 솟아오르게 해줘

20년차 메모배경과 같은 색이어서 글자와 배경의 명도 차이가 거의 없습니다. 이 스타일의 글자는 접근성 대비 기준(4.5:1)을 만족할 수 없으니 장식 제목에만 쓰고, 중요한 정보나 버튼 글자로는 쓰지 마세요. 햇빛이 센 야외 휴대폰에서는 아예 보이지 않을 수 있습니다.

04

아웃라인 Outline

글자 안을 비우고 윤곽선만 그리는 스타일입니다. 속이 찬 글자와 번갈아 놓으면 리듬이 생깁니다. 선만 있다고 해서 라인 타이포, 스트로크 텍스트라고도 합니다.

언제 쓰나대형 배경 장식 글자, 스포츠·스트리트 브랜드의 제목, 속이 찬 글자와 함께 놓는 포인트.

AI에게 이렇게아웃라인 스타일로 속이 빈 TYPE 글자 사이에 꽉 찬 글자를 끼워 넣고, 검은 배경에 흰 윤곽선만 보이게 해줘

20년차 메모얇은 선은 작은 글자에서 뭉개지고 배경 이미지 위에서는 아예 사라집니다. 글자 크기 40px 이상, 선 두께 1.5px 이상은 되어야 읽힙니다. 안을 비웠기 때문에 글자가 있는 줄 모르고 넘기는 사람이 있어, 핵심 문구는 꽉 찬 글자로 따로 쓰세요.

Type
색이 천천히 흐릅니다

05

그라데이션 Gradient

글자 안에 색이 서서히 변하는 그라데이션을 채운 스타일입니다. CSS 에서는 글자 모양으로 배경을 오려내는 background-clip: text 와 글자색을 투명하게 만드는 것이 핵심입니다.

언제 쓰나AI·핀테크·SaaS 서비스의 대표 제목, 어두운 배경의 소개 화면, 로고 옆의 슬로건.

AI에게 이렇게그라데이션 스타일로 짙은 배경 위에 분홍에서 보라, 파랑으로 이어지는 background-clip: text 제목 Type 을 만들고 색이 천천히 흐르게 해줘

20년차 메모그라데이션 한쪽 끝이 배경과 비슷한 색이 되면 그 부분 글자가 사라집니다. 가장 어두운 색과 가장 밝은 색 모두에서 대비를 확인하세요. 글자색이 투명이므로 background-clip 을 지원하지 않는 환경에서는 글자가 안 보일 수 있어 대체 글자색을 먼저 지정해야 하고, 한두 줄 제목을 넘기면 지저분해집니다.

Type
가끔 깜박입니다. 없는 글꼴은 비슷한 필기체로 보입니다

06

네온 사인 Neon sign

어두운 배경에 가는 선 글자가 스스로 빛나듯 보이게 하는 스타일입니다. 가운데는 흰색에 가깝게, 바깥은 짙은 색의 빛 번짐으로 칠하는 것이 요령입니다. 네온 글로우라고도 부릅니다.

언제 쓰나바·클럽·게임·야간 모드 콘셉트의 제목, 밤을 배경으로 한 이벤트 페이지.

AI에게 이렇게네온 사인 스타일로 어두운 보라 배경에 흰색 필기체 Type 글자와 분홍색 네 겹 글로우, 파란 밑줄을 넣고 가끔 깜박이게 해줘

20년차 메모밝은 배경에서는 빛 번짐이 보이지 않아 그냥 흐린 글자가 되고, 번짐이 너무 넓으면 작은 글자는 뭉개집니다. 큰 제목에만 쓰고 본문은 흰색 단색으로 두세요. 깜박임은 초당 3회를 넘기면 위험할 수 있어 가끔씩만 끄고 켜야 하며, 모션 줄이기 설정을 존중해야 합니다.

TYPE
가끔 지직거립니다

07

글리치 Glitch

화면 신호가 깨진 것처럼 글자가 옆으로 밀리고 빨강·파랑 계열로 갈라져 보이는 효과입니다. 글리치 효과, 색이 갈라지는 부분은 색수차(RGB split)라고 부릅니다.

언제 쓰나게임·해킹·사이버보안 콘셉트의 시작 화면, 오류 페이지의 404 숫자, 영상 인트로 제목.

AI에게 이렇게글리치 스타일로 TYPE 글자가 가끔 시안과 마젠타로 갈라지며 옆으로 밀렸다 돌아오는 효과를 CSS 만으로 만들어줘

20년차 메모계속 움직이는 글리치는 멀미를 일으킬 수 있어서, 사용자가 모션 줄이기를 켰다면 멈추게 해야 합니다(prefers-reduced-motion). 겹친 글자는 화면 읽기 프로그램에 두 번 읽히지 않도록 장식으로 숨기세요. 설정 화면이나 결제 같은 진지한 곳에 쓰면 사고가 난 것처럼 보입니다.

TYPE

08

애시드 그래픽 Acid graphic

형광 색, 물결치듯 일그러진 글자, 번지는 빛을 겹쳐서 일부러 거칠고 과하게 만든 스타일입니다. 2020년대 음악 포스터와 브랜드 캠페인에서 많이 보이고, 애시드 타이포라고도 부릅니다.

언제 쓰나공연·페스티벌 포스터, 음악 앱의 이벤트 배너, 젊은 층 대상 브랜드 캠페인의 큰 제목.

AI에게 이렇게애시드 그래픽 스타일로 검은 배경 위에 형광 연두색 TYPE 글자를 일그러뜨려서 보여줘. 글자 주변에 번지는 빛을 넣어줘

20년차 메모글자가 일그러져 있어서 제목 서너 글자를 넘기면 바로 읽히지 않습니다. 한 줄 제목에만 쓰고, 같은 문구를 보통 글자로 한 번 더 적어 두세요. 형광색은 검정 배경에서만 대비가 나오고 흰 배경에서는 거의 안 보이며, 유행이 빨리 지나가는 스타일이라 오래 쓸 브랜드 로고에는 위험합니다.

TYPE
움직임이 본질입니다. 얇은 글자와 굵은 글자를 섞었습니다

09

키네틱 Kinetic

글자가 움직이며 의미를 전하는 스타일입니다. 크기·굵기·위치가 바뀌는 것으로 리듬과 강조를 만들며, 키네틱 타이포그래피라고 부릅니다. 모션 그래픽 영상에서 먼저 발전했습니다.

언제 쓰나앱 시작 화면, 영상 인트로, 제품 소개 페이지의 첫 문구, 노래 가사 영상.

AI에게 이렇게키네틱 타이포그래피로 파란 배경에 TYPE 글자가 왼쪽부터 차례로 튀어 오르고 마지막 E 만 굵게 보이게 해줘. 모션 줄이기 설정이면 멈추게 해줘

20년차 메모읽는 글에 쓰면 사용자가 글을 읽기도 전에 움직임에 시선을 뺏깁니다. 반복은 한두 번으로 끝내고 문구는 짧게 하세요. 전정기관이 예민한 사람에게는 불편하거나 어지러울 수 있어 prefers-reduced-motion 설정이 켜져 있으면 정지한 화면으로 바꿔 주는 것까지 설계에 포함해야 합니다.
