01

리스트 List

항목을 한 줄에 하나씩 세로로 쌓은 목록. 가장 기본적인 목록 방식이며 행(row) 목록이라고도 합니다. 훑어 내려가며 비교하기 쉽습니다.

언제 쓰나연락처, 설정 메뉴, 알림처럼 글이 중심이고 항목 수가 많은 화면.

AI에게 이렇게연락처를 왼쪽 아바타와 이름, 오른쪽 화살표가 있는 리스트로 보여주고 줄 사이에 얇은 구분선을 넣어줘

실무 팁한 줄 전체를 누를 수 있어야 하는데 화살표만 눌리게 만드는 경우가 많습니다. 줄 높이는 터치 기준 44pt/48dp 이상으로 하고, 이름이 길 때 말줄임할지 줄바꿈할지 정해두세요. 항목이 하나도 없을 때의 빈 화면도 같이 그려야 합니다.

02

그리드 Grid

같은 크기의 칸을 가로세로 격자로 늘어놓은 방식. 글보다 그림이 중심일 때 한 화면에 더 많이 보여줍니다. 리스트는 한 줄에 하나, 그리드는 한 줄에 여러 개입니다.

언제 쓰나사진 앨범, 상품 둘러보기, 앱 아이콘 모음.

AI에게 이렇게상품 목록을 세 열 그리드로 만들고 화면이 좁아지면 두 열로 줄어들게 해줘

실무 팁열 수를 고정하면 큰 화면에서는 칸이 지나치게 커집니다. 칸 너비의 최소값을 정해 열 수가 자동으로 바뀌게 하세요. 사진 비율이 제각각이면 격자가 들쭉날쭉해지니 비율을 먼저 정해야 합니다. 칸 사이 간격이 너무 좁으면 눌러야 할 칸이 헷갈립니다.

제주 한 달 살기조용한 숙소 12곳
마우스를 올려 보세요

03

카드 Card

사진·제목·설명·버튼처럼 하나의 대상에 속한 정보를 테두리나 그림자로 한 덩어리로 묶은 것. 카드 하나가 하나의 대상(상품, 글, 사람)이라는 점이 그리드의 칸과 다릅니다.

언제 쓰나상품, 기사, 숙소처럼 요약 정보가 여러 종류 붙는 항목.

AI에게 이렇게숙소 정보를 카드로 만들고 사진, 제목, 가격, 찜 버튼을 넣고 카드 전체를 누르면 상세로 이동하게 해줘

실무 팁카드 안에 눌리는 곳이 너무 많으면 어디를 눌러야 할지 모릅니다. 카드 전체는 상세로, 버튼은 한두 개만 두세요. 제목이 두 줄이 되는 카드와 한 줄인 카드가 섞이면 높이가 들쭉날쭉하니 줄 수를 제한해야 합니다.

옆으로 한 장씩 넘어갑니다

04

캐러셀 Carousel

항목을 가로로 이어 붙여 놓고 한 번에 몇 개씩만 보여주며 옆으로 넘기는 방식. 슬라이더라고도 부릅니다. 한정된 세로 공간에 여러 항목을 넣을 수 있지만 안 보이는 항목은 잘 눌리지 않습니다.

언제 쓰나홈 상단 배너, 추천 상품 줄, 온보딩 이미지.

AI에게 이렇게홈 배너를 캐러셀로 만들고 아래에 현재 위치 점을 넣고 사용자가 만지면 자동 넘김이 멈추게 해줘

실무 팁자동으로 넘어가는 캐러셀은 읽는 도중에 사라져 불편하니 반드시 멈춤 수단을 두세요. 두 번째 이후 장은 거의 보지 않으니 중요한 내용은 첫 장에 넣어야 합니다. 키보드·스크린리더용 이전/다음 버튼이 없으면 접근하기 어렵습니다.

05

테이블 Table

행과 열로 같은 종류의 값을 맞춰 놓아 비교하기 좋은 목록. 열 머리글이 있어서 어느 값이 무슨 뜻인지 바로 압니다. 카드·리스트와 달리 여러 항목을 숫자별로 견주는 데 강합니다.

언제 쓰나주문 내역, 관리자 화면, 요금표, 기능 비교처럼 값이 많고 정렬·비교가 필요할 때.

AI에게 이렇게주문 목록을 테이블로 만들고 열 머리글을 누르면 정렬되게 하고 숫자 열은 오른쪽 정렬로 해줘

실무 팁모바일에서는 열이 넘쳐서 글자가 깨지니 카드로 바꾸거나 가로 스크롤을 두는 방법을 미리 정해야 합니다. 숫자 열은 오른쪽 정렬로 자릿수를 맞추세요. 디자인용 표를 만들면서 <table> 대신 div로 짜면 스크린리더가 표로 읽지 못합니다.

06

타임라인 Timeline

일어난 일을 시간 순서로 세로선 위에 이어서 보여주는 방식. 항목 사이의 순서와 시간 간격이 정보의 핵심입니다. 활동 기록, 히스토리라고도 부릅니다.

언제 쓰나배송 추적, 주문 진행 상태, 변경 이력, 소셜 피드.

AI에게 이렇게배송 상태를 세로 타임라인으로 만들고 지난 단계는 채워진 점, 지금 단계는 강조해서 보여줘

실무 팁점과 선 색만으로 지난 단계/현재/예정을 구분하면 색약 사용자가 알기 어려우니 아이콘이나 글로도 구분하세요. 시간이 오래된 순인지 최신순인지 정하지 않으면 화면마다 달라집니다. 기록이 수백 개일 때는 날짜별로 묶는 방법이 필요합니다.

환불은 어떻게 하나요?

주문 내역에서 신청합니다.

배송은 얼마나 걸리나요?

보통 2~3일 걸립니다.

회원 탈퇴는 어디서 하나요?

설정에서 할 수 있습니다.

제목을 눌러 보세요

07

아코디언 Accordion

제목만 보이다가 눌러야 내용이 펼쳐지는 목록. 아코디언 악기의 주름처럼 접히고 펴져서 붙은 이름입니다. HTML에는 <details> 태그가 기본으로 있습니다.

언제 쓰나자주 묻는 질문(FAQ), 설정 그룹, 긴 상품 설명의 일부 접기.

AI에게 이렇게FAQ를 아코디언으로 만들고 한 번에 하나만 열리게 하고 열린 항목은 화살표가 돌아가게 해줘

실무 팁중요한 내용을 접어 두면 아무도 안 열어 봅니다. 사용자가 거의 다 읽어야 하는 정보는 펼쳐 두세요. 제목 줄 전체가 눌려야 하고 펼침 상태를 화살표 방향과 aria-expanded로 알려야 합니다. 한 번에 하나만 열지, 여러 개를 허용할지도 정해야 합니다.

08

메이슨리 Masonry

높이가 다른 사진을 세로 칸마다 빈틈없이 쌓는 배치. 벽돌공(mason)이 벽돌을 쌓는 모양에서 왔습니다. 칸 높이가 같은 그리드와 달리 사진의 원래 비율을 살립니다.

언제 쓰나핀터레스트식 이미지 모음, 디자인 레퍼런스 갤러리, 후기 사진 모음.

AI에게 이렇게이미지 목록을 CSS columns를 쓴 메이슨리 레이아웃으로 만들고 세 열이 두 열로 줄어들게 해줘

실무 팁CSS columns 방식은 항목이 위에서 아래로 칸을 채우므로 가로 방향 순서가 뒤섞여 키보드로 이동하면 순서가 이상합니다. 순서가 중요한 목록(최신순 등)에는 맞지 않습니다. 이미지 로딩 전에 높이를 모르면 로딩할 때마다 화면이 흔들립니다.

단순화한 예시: 바닥에 닿으면 새 항목이 이어집니다

09

무한 스크롤 Infinite scroll

바닥까지 내려가면 다음 항목이 자동으로 이어 붙는 방식. 인피니트 스크롤 또는 끝없는 스크롤이라고 합니다. 페이지를 나누는 방식과 달리 누르지 않아도 계속 나옵니다.

언제 쓰나소셜 피드, 뉴스 피드, 영상·사진 추천처럼 끝이 없고 훑어보는 목록.

AI에게 이렇게피드를 무한 스크롤로 만들고 바닥 근처에서 다음 20개를 불러오며 불러오는 동안 하단에 스피너를 보여줘

실무 팁푸터(하단 링크)에 닿을 수 없어서 약관이나 고객센터를 못 찾는 사고가 납니다. 찾는 목적이 있는 목록(상품 검색)에는 어울리지 않고, 뒤로 가기를 하면 스크롤 위치가 맨 위로 돌아가는 문제를 개발자와 점검하세요. 끝났을 때 "마지막입니다" 표시도 필요합니다.

10

페이지네이션 Pagination

목록을 쪽으로 나누고 번호로 이동하게 하는 방식. 무한 스크롤과 반대로 사용자가 어디쯤인지 알 수 있습니다.

언제 쓰나검색 결과, 게시판, 관리자 목록처럼 특정 항목을 다시 찾아야 할 때. 데스크톱 웹.

AI에게 이렇게목록 아래에 페이지네이션을 넣고 현재 쪽은 강조하고 이전/다음 버튼과 최대 5개의 번호를 보여줘

실무 팁번호 칸이 너무 작아 모바일에서 잘못 눌립니다. 전체 쪽 수가 많을 때 생략 표시(…)를 어떻게 할지와, 현재 쪽을 주소에 남겨 새로고침해도 유지하는지도 확인하세요.

11

더 보기 버튼 Load more

목록 맨 아래에 버튼을 놓고 눌러야 다음 항목을 가져오는 방식. 무한 스크롤과 페이지네이션 사이의 절충안입니다.

언제 쓰나후기 목록, 댓글, 푸터를 반드시 보여줘야 하는 목록.

AI에게 이렇게후기 목록 아래에 더 보기 버튼을 두고 누를 때마다 10개씩 이어서 보여주며 남은 개수를 표시해줘

실무 팁버튼을 눌렀을 때 로딩 상태와 새 항목이 들어온 뒤 포커스 위치를 놓치기 쉽습니다. 키보드 사용자가 새로 생긴 첫 항목으로 이동하게 해주세요. 더 이상 없을 때는 버튼을 없애세요.

12

고정 머리글 Sticky header

목록을 내려도 현재 구역의 제목이 위에 붙어 따라오는 방식. CSS position: sticky로 만듭니다. 그룹으로 나뉜 긴 리스트에서 지금 어디인지 알려줍니다.

언제 쓰나연락처 가나다 순, 날짜별 내역, 표의 열 머리글.

AI에게 이렇게연락처 목록에 초성별 머리글을 달고 스크롤해도 위에 고정되게 해줘

실무 팁고정 머리글이 화면의 상단 바와 겹치면 둘 다 가려지니 top 값을 맞춰야 합니다. 모바일에서 키보드가 올라오면 고정 요소가 화면을 너무 차지하는 점도 확인하세요.
