00

빈 상태 화면 Empty state

보여줄 내용이 아직 없는 화면을 디자인된 화면으로 만든 것. 안내 아이콘, 한 줄 설명, 다음에 할 행동 버튼 세 가지가 기본 구성입니다. 아래 아홉 가지는 모두 이 빈 상태 화면의 종류입니다.

언제 쓰나목록, 찜, 장바구니, 알림함, 검색 결과처럼 데이터가 채워지기 전이나 사라진 뒤의 모든 화면.

AI에게 이렇게찜 목록이 비어 있으면 빈 상태 화면으로 보여줘. 아이콘과 한 줄 설명, "물건 보러 가기" 행동 버튼을 넣어줘

20년차 메모"꾸며줘"라고 하면 AI는 화려한 일러스트와 "데이터가 없습니다" 같은 개발자의 말을 내놓습니다. 사용자에게 필요한 건 장식이 아니라 "왜 비었는지, 지금 뭘 하면 되는지"입니다. 목록 화면을 만들 때는 빈 상태를 맨 처음에 같이 시키는 습관을 들이세요.

아직 지원한 곳이 없어요

첫 지원서를 만들면 여기에 모여요

01

첫 사용 First use

새로 가입했거나 처음 열어서 아직 아무것도 쌓이지 않은 화면. 사용자의 잘못이 아니라 당연한 상태이므로 시작하는 방법을 가르쳐주는 곳이 됩니다.

언제 쓰나신규 가입 직후의 홈, 첫 프로젝트 목록, 처음 열어 본 내 지원 내역.

AI에게 이렇게지원 내역이 하나도 없는 첫 사용 상태에서는 "첫 지원서 만들기" 버튼이 있는 빈 화면을 보여줘

20년차 메모이 화면은 제품을 처음 만나는 사람이 가장 먼저 보는 곳인데 가장 대충 만들어집니다. 개발할 때 데이터가 들어 있는 상태로만 확인하니까 빈 상태를 아무도 못 봅니다. 새 계정으로 직접 가입해서 눈으로 확인하세요.

"포트폴리옹"에 맞는 결과가 없어요

철자를 확인하거나 더 짧은 단어로 찾아보세요

02

검색 결과 없음 No search results

사용자가 검색어를 직접 입력했는데 맞는 것이 없는 화면. 첫 사용과 달리 사용자가 방금 한 행동의 결과이므로 검색어를 되돌려 보여주고 다른 길을 제시해야 합니다.

언제 쓰나검색창에 입력한 단어로 찾을 수 있는 결과가 0개일 때.

AI에게 이렇게검색 결과가 0개면 입력한 검색어를 보여주고 철자 확인 안내와 인기 검색어를 함께 보여줘

20년차 메모"결과 없음"이라고만 하면 막다른 길입니다. 비슷한 검색어 추천, 인기 항목, 필터 해제 같은 출구를 꼭 하나는 주세요. 한 글자씩 입력하는 도중에 결과 없음이 깜빡이는 일이 없도록 입력이 끝난 뒤에 보여줘야 합니다.

03

필터 결과 없음 No filter results

전체 목록에는 내용이 있지만 사용자가 건 조건에 맞는 것이 없는 화면. 검색 결과 없음과 비슷하지만 조건을 풀면 해결되므로 "필터 초기화" 버튼이 핵심입니다.

언제 쓰나쇼핑몰의 가격·색상 필터, 채용 공고의 지역·연봉 필터를 겹쳐 걸었을 때.

AI에게 이렇게필터 결과가 없으면 지금 적용된 조건을 칩으로 보여주고 "필터 초기화" 버튼이 있는 빈 화면을 띄워줘

20년차 메모가장 흔한 사고는 필터를 걸어 둔 걸 잊고 "데이터가 없네?" 하며 서비스를 떠나는 것입니다. 적용 중인 필터를 화면 위에 계속 보이게 두고, 칩 하나만 눌러도 풀리게 만드세요. 조건을 하나 빼면 몇 건이 나오는지 알려 주면 더 좋습니다.

인터넷에 연결되어 있지 않아요

연결되면 자동으로 다시 불러올게요

04

오프라인 Offline

네트워크가 끊겨서 내용을 불러올 수 없는 화면. 서비스의 잘못이 아니라 연결 문제임을 알려, 사용자가 서비스 오류와 구별하게 해줍니다.

언제 쓰나지하철·엘리베이터처럼 신호가 끊긴 순간, 비행기 모드, 와이파이가 불안정할 때.

AI에게 이렇게인터넷이 끊기면 오프라인 화면을 보여주고, 연결이 돌아오면 자동으로 새로고침해줘

20년차 메모이미 불러온 내용이 있다면 화면을 통째로 오프라인 화면으로 바꾸지 말고, 내용은 남겨 둔 채 위에 작은 배너만 띄우세요. 사용자가 입력하던 글이 있다면 반드시 보존해야 합니다. 서버가 죽은 오류와 구분하는 것도 중요합니다.

카메라 권한이 필요해요

명함을 촬영하려면 카메라를 켜야 해요

05

권한 필요 Permission needed

카메라, 위치, 알림처럼 기기의 허락이 필요한 기능을 사용자가 거절해서 쓸 수 없는 화면. 왜 필요한지와 어디서 허용하는지를 알려줘야 합니다.

언제 쓰나카메라 촬영, 사진 올리기, 지도 위치 보기를 눌렀는데 권한이 꺼져 있을 때.

AI에게 이렇게카메라 권한이 거절된 상태에서는 이유를 설명하고 "설정에서 허용하기" 버튼으로 기기 설정을 열어주는 권한 필요 화면을 만들어줘

20년차 메모iOS와 안드로이드는 한 번 거절하면 앱이 시스템 허용 창을 다시 띄울 수 없는 경우가 많아서, 이 화면이 유일한 구조 신호가 됩니다. 허용을 요청하기 전에 이유를 먼저 설명하는 화면을 두면 거절률이 줄어듭니다. 웹에서는 브라우저마다 허용을 다시 켜는 방법이 달라 안내 문구가 따로 필요합니다.

모든 알림을 확인했어요

새 소식이 오면 알려드릴게요

06

모두 완료 All caught up

쌓여 있던 할 일·알림을 다 처리해서 비어 있는 화면. 다른 빈 화면이 "아직 없음"이라면 이건 "다 했음"이라는 좋은 소식이라 칭찬하는 톤이 어울립니다. 인박스 제로라고도 합니다.

언제 쓰나안 읽은 메일함을 비웠을 때, 오늘 할 일을 모두 끝냈을 때, 알림을 모두 읽었을 때.

AI에게 이렇게알림을 전부 읽으면 체크 아이콘과 "모든 알림을 확인했어요" 문구가 있는 모두 완료 화면을 보여줘

20년차 메모"아무것도 없습니다"처럼 쓰면 오류처럼 보입니다. 처음부터 비어 있는 화면(첫 사용)과 해냈기 때문에 비어 있는 화면은 문구와 아이콘이 달라야 합니다. 다음에 할 만한 행동을 굳이 억지로 붙이지 않아도 됩니다.

모두 삭제했어요

지운 항목은 30일 동안 보관돼요

07

삭제 직후 Emptied

사용자가 직접 항목을 모두 지워서 방금 비어진 화면. 방금 한 행동의 결과이므로 "되돌리기"를 줄 수 있다는 점이 첫 사용과 다릅니다.

언제 쓰나장바구니 비우기, 휴지통 비우기, 최근 검색어 전체 삭제 직후.

AI에게 이렇게장바구니를 전부 비우면 "모두 삭제했어요" 안내와 되돌리기 버튼이 있는 빈 화면을 보여줘

20년차 메모첫 사용 화면을 그대로 재사용하면 방금 지운 사람에게 "아직 아무것도 없어요"라고 말하는 어색한 일이 생깁니다. 되돌리기는 화면에 머무는 시간(보통 몇 초)이 지나면 사라지니 완전 삭제와 휴지통 보관 중 어느 쪽인지 개발자와 먼저 정해야 합니다.

목록을 불러오지 못했어요

잠시 후 다시 시도해 주세요

08

오류 화면 Error state

서버나 프로그램에 문제가 생겨 내용을 보여줄 수 없는 화면. 오프라인과 달리 서비스 쪽의 문제이며, 비어 있는 게 아니라 "못 가져온 것"입니다.

언제 쓰나서버 점검, 응답 실패, 예상치 못한 프로그램 오류로 목록·상세를 못 불러올 때.

AI에게 이렇게목록 API가 실패하면 오류 상태 화면에 "다시 시도" 버튼을 보여주고, 누르면 다시 요청해줘

20년차 메모오류를 "비어 있음"으로 잘못 보여주는 것이 최악의 실수입니다. 실제로는 데이터가 있는데 사용자는 사라졌다고 오해합니다. "오류 코드 500" 같은 말 대신 사용자가 할 수 있는 일(다시 시도, 문의)을 말하고, 개발자용 오류 정보는 접어 두세요.

멤버십 전용 콘텐츠예요

가입하면 모든 강의를 볼 수 있어요

09

잠김 Locked content

내용은 있지만 로그인이나 결제, 등급이 없어서 볼 수 없는 화면. "없어서"가 아니라 "자격이 없어서" 비어 있다는 점이 다른 빈 화면과 다릅니다. 페이월(paywall)이라고도 부릅니다.

언제 쓰나유료 강의, 회원 전용 게시판, 관리자만 보는 메뉴를 자격 없는 사용자가 열었을 때.

AI에게 이렇게멤버십이 없는 사용자가 강의를 열면 자물쇠 아이콘과 가입 안내, "멤버십 보기" 버튼이 있는 잠김 화면을 보여줘

20년차 메모"접근 권한이 없습니다"라는 차가운 문장은 사용자를 쫓아냅니다. 무엇을 하면 열 수 있는지(로그인, 결제, 승인 요청)를 한 줄로 알려주세요. 내용 일부를 미리 보여주면 가입 동기가 되지만, 보안이 필요한 정보는 화면만 가리지 말고 서버에서 아예 내려주지 않아야 합니다.

10

샘플 데이터 Sample data

빈 화면 대신 예시 내용을 미리 채워 두는 방법. 사용자가 완성된 화면이 어떤 모습인지 바로 보고, 직접 만들기 전에 느낌을 잡을 수 있습니다.

언제 쓰나노트, 대시보드, 템플릿 서비스처럼 처음 열었을 때 텅 비면 쓰임을 알기 어려운 곳.

AI에게 이렇게처음 가입한 사용자의 대시보드에는 "예시" 딱지가 붙은 샘플 데이터를 보여주고, 첫 항목을 만들면 지워줘

20년차 메모샘플이 진짜 데이터와 섞여 통계가 틀어지는 사고가 가장 흔합니다. "예시"라고 분명히 표시하고, 지우기 쉽게 해야 하며, 집계에서는 반드시 빼야 합니다.

11

404 화면 Not found page

주소(URL)에 해당하는 페이지가 없을 때 뜨는 화면. 숫자 404는 "없음"을 뜻하는 웹의 표준 상태 코드입니다. 화면 하나가 통째로 없는 경우라 목록이 비는 빈 상태 화면과 다릅니다.

언제 쓰나잘못 입력한 주소, 삭제된 글, 옮겨진 페이지로 들어왔을 때.

AI에게 이렇게없는 주소로 접속하면 404 화면을 보여주고 홈으로 가기 버튼과 검색창을 넣어줘

20년차 메모재치 있는 일러스트보다 출구가 중요합니다. 홈, 검색, 인기 페이지로 가는 길 하나는 꼭 두세요. 개발할 때 화면은 404를 보이는데 서버는 200으로 응답하는 일이 있어 검색 노출에 문제가 생기니 확인해야 합니다.
