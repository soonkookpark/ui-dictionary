검색 화면 이름 9가지

검색 화면의 이름을 알면 말하기가 쉬워요

눌러서 글자를 써 보세요

01

검색창 Search bar

검색어를 직접 입력하는 칸. 돋보기 아이콘이 있으면 검색이라고 알아봅니다. 입력이 시작되면 지우기 버튼(X)이 나타나는 것이 보통입니다.

언제 쓰나상품, 글, 사람처럼 항목이 너무 많아 목록을 훑을 수 없을 때. 홈 상단이나 헤더.

AI에게 이렇게상단에 둥근 검색창을 만들고 안에 돋보기 아이콘, 입력하면 지우기 버튼을 보이게 하고 엔터로 검색되게 해줘

20년차 메모돋보기 아이콘만 있는 버튼으로 줄이면 사용자가 검색인 줄 모를 때가 많으니 중요한 서비스는 입력칸을 열어두세요. placeholder를 라벨 대신 쓰면 입력하는 순간 설명이 사라집니다. 아이콘 버튼에는 "검색"이라는 이름이 필요하고 모바일에서는 키보드의 엔터키 모양을 "검색"으로 바꿔야 합니다.

02

자동완성 Autocomplete

글자를 치는 동안 입력창 아래에 후보를 띄워 주는 기능. 끝까지 치지 않고 골라서 시간을 줄입니다. 영어로 typeahead, suggestions라고도 합니다.

언제 쓰나검색어가 길거나 철자가 헷갈릴 때, 상품명처럼 후보가 많은 검색.

AI에게 이렇게검색창에 글자를 입력하면 아래에 최대 5개의 자동완성 후보를 보여주고 일치한 글자는 굵게 표시해줘

20년차 메모한글은 조합 중인 글자(ㅇ, 아, 아이)가 입력 이벤트를 여러 번 일으켜 후보가 깜빡거리는 문제가 자주 생깁니다. 개발자와 조합이 끝난 뒤 보여줄지 정하세요. 후보를 키보드 위아래 화살표로 고를 수 있어야 하고, 후보가 없을 때 빈 상자가 남지 않게 해야 합니다.

03

최근 검색어 Recent searches

내가 전에 찾았던 말을 다시 보여주는 목록. 검색창을 누른 순간에 나타나 다시 입력하는 수고를 덜어줍니다. 검색 기록(search history)이라고도 합니다.

언제 쓰나검색창을 눌렀지만 아직 아무 글자도 안 쳤을 때의 빈 화면.

AI에게 이렇게검색창을 누르면 최근 검색어를 칩으로 보여주고 개별 삭제 버튼과 전체 삭제를 넣어줘

20년차 메모공용 기기에서는 개인 정보라 끌 수 있어야 합니다. 삭제 버튼이 칩에 붙어 있으면 터치할 때 검색어 대신 삭제가 눌리니 각각 44pt/48dp 영역을 확보하세요. 최대 개수(보통 10개 안팎)를 정해 오래된 것은 밀어내야 합니다.

04

인기 검색어 Trending

많은 사람이 최근에 찾은 검색어를 순위로 보여주는 목록. 지금 무엇이 인기인지 알려줘 검색의 시작점을 줘서, 내가 찾는 것을 모르는 사용자도 둘러볼 수 있습니다. 실시간 검색어, 급상승 검색어라고도 부릅니다.

언제 쓰나검색창을 눌렀을 때 아래, 홈의 검색 영역.

AI에게 이렇게검색창 아래에 인기 검색어 5개를 1위부터 순위와 함께 보여주고 순위 변동 화살표를 붙여줘

20년차 메모집계 기준(최근 1시간인지 하루인지)을 안 정하면 화면이 계속 바뀌어 산만하고, 부적절한 단어가 순위에 오를 수 있어 걸러내는 기준이 필요합니다. 순위 변동을 색으로만 표시하지 말고 화살표 모양도 쓰세요. 숫자와 이름 사이가 좁으면 두 자리 순위에서 줄이 흐트러집니다.

05

필터 Filter

결과 중에서 조건에 맞지 않는 것을 빼서 줄이는 기능. 정렬이 순서를 바꾼다면 필터는 목록에 남는 것 자체를 바꿉니다. 쓰는 만큼 결과가 줄어듭니다.

언제 쓰나상품 검색, 숙소 목록, 채용 공고처럼 조건이 많은 검색 결과.

AI에게 이렇게검색 결과 위에 가로 스크롤 필터 칩을 만들고 선택한 필터는 색을 채우고 결과 수가 바로 바뀌게 해줘

20년차 메모필터를 많이 걸다 보면 결과가 0개가 되는 일이 흔한데 어떤 필터를 풀어야 할지 알려주지 않으면 사용자는 막힙니다. 선택된 필터를 한곳에 모아 보여주고 한 번에 해제하는 버튼을 두세요. 모바일에서는 필터가 많으면 전체 화면 시트로 따로 빼는 것이 맞습니다.

눌러 보세요

06

정렬 Sort

결과 목록을 어떤 기준의 순서로 놓을지 정하는 기능. 필터와 달리 결과 개수는 그대로이고 순서만 바뀝니다. sort order라고도 합니다.

언제 쓰나검색 결과, 상품 목록, 후기 목록. 보통 목록 위 오른쪽에 둡니다.

AI에게 이렇게결과 목록 위에 인기순, 최신순, 낮은 가격순을 고르는 정렬 버튼을 만들고 현재 선택한 기준을 강조해줘

20년차 메모기본 정렬이 무엇인지 안 정해 두면 같은 검색어도 사람마다 다른 순서가 나옵니다. 정렬 항목이 4개를 넘으면 한 줄에 못 들어가니 드롭다운이나 바텀 시트로 바꿔야 합니다. "인기순" 같은 기준이 실제로 무엇을 기준으로 하는지 개발자와 정의해 두세요.

07

검색어 강조 Highlight

검색 결과 글 속에서 내가 친 말과 일치하는 부분을 형광펜처럼 칠해 주는 것. HTML에는 <mark> 태그가 이 용도로 준비되어 있습니다. 결과가 왜 나왔는지 바로 알게 합니다.

언제 쓰나검색 결과의 제목과 요약 글, 문서 안 찾기.

AI에게 이렇게검색 결과의 제목과 요약에서 검색어와 일치하는 부분을 mark 태그로 노란색으로 강조해줘

20년차 메모일치한 글자를 정규식으로 바꿔치기할 때 "에어팟"이 "에어팟 프로" 중 어디까지 칠해질지, 특수문자가 들어간 검색어가 화면을 깨뜨리는지 개발자와 확인하세요. 형광색 위 글자의 대비는 4.5:1이 되도록 글자를 어둡게 쓰고, 너무 많이 칠하면 오히려 읽기 힘듭니다.

'에어팥' 결과가 없어요철자를 확인하거나 다른 검색어로 찾아보세요

08

결과 없음 No results

검색했지만 맞는 결과가 하나도 없을 때의 화면. 막다른 길이 되기 쉬워서 다음에 할 수 있는 행동을 제안해야 하는 화면입니다. 빈 상태(empty state)의 한 종류입니다.

언제 쓰나검색 결과가 0건이거나, 필터를 걸어 결과가 모두 사라졌을 때.

AI에게 이렇게검색 결과가 없으면 검색어를 보여주고 철자 확인 안내와 인기 검색어, 필터 초기화 버튼을 보여줘

20년차 메모그냥 "결과가 없습니다"만 쓰고 끝내는 경우가 가장 흔한 실수입니다. 오타 교정 제안, 검색어를 줄이는 방법, 인기 항목처럼 이동할 곳을 같이 주세요. 사용자가 입력한 단어를 화면에 다시 보여줘야 오타를 알아봅니다.

눌러 보세요

09

검색 범위 탭 Scope tabs

검색 결과를 종류별로 나눠 보게 하는 탭. 전체 검색 결과 위에 "전체·상품·후기"처럼 놓입니다. 범위를 좁히는 점은 필터와 비슷하지만 서로 다른 종류의 데이터를 가르는 점이 다릅니다.

언제 쓰나상품과 후기, 사람과 게시글처럼 결과 종류가 섞이는 서비스.

AI에게 이렇게검색 결과 위에 전체, 상품, 후기, 브랜드 탭을 만들고 탭마다 결과 개수를 괄호로 보여줘

20년차 메모탭을 누를 때마다 검색어가 유지되는지 확인하세요. 탭을 바꾸면 입력창이 비워지는 버그가 흔합니다. 탭이 5개를 넘으면 가로 스크롤이 필요하고, 현재 탭을 색으로만 표시하지 말고 밑줄 같은 모양도 더하세요.

캡쳐엔 없지만 알아둘 용어

실무에서 검색 화면을 이야기할 때 함께 나오는 말들입니다.

10

오타 교정 Did you mean

입력한 검색어가 오타 같을 때 "혹시 ~를 찾으셨나요?"라고 바른 후보를 제안하는 기능. 결과가 없어지는 것을 막아 줍니다.

언제 쓰나결과 수가 적거나 0건인 검색, 외래어·상품명처럼 철자가 어려운 검색.

AI에게 이렇게검색 결과가 적을 때 맨 위에 "혹시 ~를 찾으셨나요?"를 보여주고 누르면 그 검색어로 다시 검색해줘

20년차 메모자동으로 고쳐서 결과를 보여 주면 사용자가 원한 단어가 아니었을 때 혼란스러우니, 어떤 말로 검색했는지 반드시 알려주세요. 원래 검색어 그대로 찾을 수 있는 선택지도 남겨야 합니다.

'운동화' 검색 결과 1,284건

11

결과 개수 Result count

검색 결과가 몇 개인지 알려주는 숫자. 내가 지금 좁혀진 범위인지 넓은 범위인지 감을 잡게 해줍니다.

언제 쓰나검색 결과 목록의 맨 위, 필터를 켜고 끄는 사이에 바뀌는 숫자.

AI에게 이렇게검색 결과 맨 위에 검색어와 전체 결과 개수를 보여주고 필터를 바꿀 때마다 실시간으로 갱신해줘

20년차 메모숫자가 매우 크면 "1만건 이상"처럼 어림해도 됩니다. 정확한 수를 계산하느라 느려지는 경우가 있어서 개발자와 상의하세요. 숫자가 바뀔 때 스크린리더에도 바뀐 값을 알려야 합니다.

듣고 있어요

12

음성 검색 Voice search

키보드 대신 말로 검색어를 입력하는 기능. 검색창 오른쪽 마이크 버튼으로 시작하며, 말하는 동안 듣고 있다는 움직임을 보여줍니다.

언제 쓰나운전 중이나 긴 말을 치기 힘든 모바일, 입력하기 어려운 이름이 필요한 곳.

AI에게 이렇게검색창 오른쪽에 마이크 버튼을 넣고 누르면 듣는 중 표시를 보여주고 인식된 말을 검색창에 채워줘

20년차 메모마이크 권한을 처음 누를 때 묻는 화면과 거절했을 때의 안내를 같이 설계해야 합니다. 인식이 틀릴 때 수정할 수 있게 글로 먼저 보여준 뒤 검색하세요. 주변이 시끄러울 때의 실패 화면도 필요합니다.
