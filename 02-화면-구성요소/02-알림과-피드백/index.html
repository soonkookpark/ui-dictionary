01

토스트 Toast

화면 한쪽에 작은 글상자가 잠깐 떴다가 저절로 사라집니다. 구운 토스트가 톡 튀어나오는 모습에서 따온 이름입니다. 눌러야 하는 버튼이 없습니다.

언제 쓰나"저장했어요", "링크를 복사했어요"처럼 결과만 알려주면 끝나는 가벼운 안내.

AI에게 이렇게저장 버튼을 누르면 화면 아래에 "저장했어요" 토스트를 3초 동안 보여줘

20년차 메모저절로 사라지기 때문에 놓치면 끝입니다. 오류나 되돌릴 수 없는 결과처럼 꼭 읽어야 하는 내용에는 쓰지 마세요. 또 화면 낭독기 사용자를 위해 알림 영역(aria-live)으로 읽히게 만들어야 하는데, 이걸 빼먹는 경우가 많습니다.

02

스낵바 Snackbar

토스트처럼 잠깐 뜨지만 옆에 행동 버튼(되돌리기 등)이 붙은 막대입니다. 구글 머티리얼 디자인에서 쓰는 이름이고, 토스트와 같은 뜻으로 섞어 부르는 경우도 많습니다.

언제 쓰나삭제·이동처럼 실수했을 때 바로 되돌릴 기회를 주고 싶은 동작 뒤.

AI에게 이렇게항목을 삭제하면 아래에 "되돌리기" 버튼이 있는 스낵바를 5초 동안 보여주고, 누르면 복구해줘

20년차 메모되돌리기 버튼이 있는데 3초 만에 사라지면 눌러 볼 틈이 없습니다. 최소 5초는 두고, 마우스를 올려 두는 동안에는 시간이 멈추게 하세요. 그리고 이 시간 안에는 서버에서 실제로 지우지 말고 기다렸다가 지워야 진짜 되돌려집니다.

서류 마감이 3일 남았어요x

03

배너 Banner

화면 위쪽(또는 아래)에 붙어서 사용자가 닫을 때까지 머무는 안내 띠입니다. 토스트와 달리 화면 흐름 안에 자리를 차지합니다.

언제 쓰나점검 공지, 마감 임박, 결제 수단 만료처럼 한동안 계속 알려야 하는 상태.

AI에게 이렇게목록 위에 마감 임박을 알려주는 파란 배너를 넣고, 오른쪽 X로 닫을 수 있게 해줘

20년차 메모배너를 여러 개 겹쳐 쌓으면 정작 내용이 화면 아래로 밀려납니다. 한 번에 하나만 보여주세요. 닫은 배너가 새로고침하면 또 뜨는 것도 흔한 불만이니, 닫았다는 사실을 기억하게 만들어야 합니다.

04

모달 Modal dialog

뒤 화면을 어둡게 덮고 가운데에 뜨는 창. 사용자가 답하기 전에는 뒤 화면을 누를 수 없습니다. 다이얼로그, 팝업이라고도 부르지만 팝업은 더 넓은 말입니다.

언제 쓰나제출, 삭제, 결제처럼 되돌릴 수 없는 일을 하기 직전의 마지막 확인.

AI에게 이렇게제출 버튼을 누르면 "취소"와 "제출" 버튼이 있는 모달을 띄우고, 바깥을 눌러도 닫히지 않게 해줘

20년차 메모모달은 사용자의 흐름을 끊는 가장 강한 알림이라 남발하면 바로 미움받습니다. 버튼 문구를 "예/아니오" 대신 "제출"·"취소"처럼 동작으로 쓰세요. Esc 키로 닫히는지, 열린 동안 키보드 포커스가 창 안에 갇히는지도 꼭 확인해야 합니다.

공유하기이름 바꾸기삭제하기

05

바텀시트 Bottom sheet

화면 아래에서 올라오는 판. 모달이 가운데에 뜨는 창이라면 바텀시트는 엄지손가락이 닿는 아래쪽에서 올라옵니다. 위 손잡이를 끌어 닫는 경우가 많습니다.

언제 쓰나모바일에서 "더보기" 메뉴, 옵션 고르기, 공유 목록처럼 선택지가 여러 개일 때.

AI에게 이렇게점 세 개 버튼을 누르면 공유·이름 바꾸기·삭제 항목이 있는 바텀시트가 아래에서 올라오게 해줘

20년차 메모PC 화면에서는 어색해서 보통 일반 모달이나 드롭다운으로 바꿉니다. 삭제처럼 위험한 항목은 빨간색으로 구분하고 맨 아래에 두세요. 아래로 끌어 닫는 제스처 말고도 닫기 버튼이 있어야 접근성이 지켜집니다.

이메일 형식이 아니에요. 예: woody@mail.com 입력하면 바로 알려줍니다

06

인라인 오류 Inline error

잘못된 입력칸 바로 옆이나 아래에 빨간 글씨로 이유를 적어주는 방식입니다. 화면 위쪽에 오류를 한꺼번에 모아 보여주는 것과 다릅니다.

언제 쓰나회원가입, 주문서, 로그인처럼 입력칸이 있는 모든 폼.

AI에게 이렇게이메일 입력칸에서 포커스가 빠질 때 형식이 틀리면 칸 아래에 빨간 인라인 오류 문구를 보여줘

20년차 메모빨간색만으로 오류를 알리면 색을 구별하기 어려운 사용자는 놓칩니다. 아이콘이나 글자를 꼭 함께 쓰세요. 그리고 "잘못된 입력입니다" 같은 말은 쓸모없고, 어떻게 고쳐야 하는지까지 적어야 합니다. 타이핑 중간마다 바로 띄우면 공격받는 느낌이라 입력을 마친 뒤에 보여주는 편이 좋습니다.

07

툴팁 Tooltip

요소에 마우스를 올리거나 포커스가 가면 옆에 뜨는 작은 설명 말풍선. 눌러서 열고 닫는 팝오버(popover)보다 가볍고, 안에 버튼을 넣지 않습니다.

언제 쓰나아이콘 버튼의 이름, 낯선 용어의 한 줄 풀이처럼 짧은 보충 설명.

AI에게 이렇게합격률 옆 물음표 아이콘에 마우스를 올리거나 포커스하면 툴팁으로 기준을 설명해줘

20년차 메모터치 화면에는 "올리기"가 없어서 모바일에서는 툴팁이 사실상 안 보입니다. 꼭 필요한 정보는 툴팁에 숨기지 말고 화면에 직접 쓰세요. 키보드 포커스에서도 뜨는지, 읽다가 마우스를 옮겨도 바로 사라지지 않는지 확인해야 합니다.

08

코치마크 Coach mark

화면을 어둡게 덮고 알려줄 부분만 밝게 남긴 채 사용법을 짚어주는 안내. 처음 쓰는 사람에게 코치가 옆에서 가리켜 주는 모양이라 이런 이름이 붙었습니다. 온보딩 툴팁, 스포트라이트 투어라고도 합니다.

언제 쓰나앱을 처음 열었을 때, 또는 새 기능이 추가된 직후 그 기능의 위치를 알려줄 때.

AI에게 이렇게처음 접속한 사용자에게만 + 버튼을 밝게 강조하고 나머지는 어둡게 덮는 코치마크를 한 번 보여줘

20년차 메모한 번에 3개 이상 보여주면 아무도 끝까지 읽지 않습니다. 그리고 "알겠어요"를 누른 뒤 다시 볼 방법이 없으면 곤란하니, 도움말 어딘가에 다시 보기를 두세요. 화면 크기가 달라질 때 구멍 위치가 어긋나는 개발 문제도 자주 터집니다.

09

뱃지 Badge

아이콘 모서리에 붙는 작은 숫자나 점. 소리 없이 "확인하지 않은 것이 있다"고 알려줍니다. 숫자가 없는 점만 있는 것은 점 뱃지(dot badge)라고 합니다.

언제 쓰나알림 종, 채팅 아이콘, 앱 아이콘, 탭 메뉴에서 읽지 않은 항목이 있을 때.

AI에게 이렇게알림 아이콘 오른쪽 위에 읽지 않은 개수를 보여주는 빨간 뱃지를 달고, 99개가 넘으면 99+로 표시해줘

20년차 메모모든 메뉴에 뱃지를 달면 빨간색이 일상이 되어 아무도 신경 쓰지 않습니다. 정말 사용자의 행동이 필요한 곳에만 쓰세요. 숫자가 두 자리·세 자리로 늘어날 때 동그라미가 찌그러지지 않는지, 읽으면 사라지는지도 꼭 확인합니다.

10

푸시 알림 Push notification

앱을 열어 두지 않아도 기기의 잠금 화면과 상단에 도착하는 알림. 앞의 9가지가 앱 안의 알림이라면 푸시는 앱 밖에서 사용자를 부르는 알림입니다.

언제 쓰나배송 출발, 채팅 도착, 결제 완료처럼 지금 알려야 의미가 있는 소식.

AI에게 이렇게지원서가 열람되면 푸시 알림을 보내고, 설정에서 종류별로 끌 수 있게 해줘

20년차 메모첫 실행 때 바로 "알림을 허용하시겠어요?"를 띄우면 대부분 거절당하고, 거절한 뒤에는 앱이 다시 물을 수 없습니다. 왜 필요한지 먼저 보여주고, 사용자가 필요를 느낀 순간에 허용을 요청하세요.

단순화한 예시: 실제로는 기기가 진동합니다

11

햅틱 피드백 Haptic feedback

화면이 아니라 진동으로 알려주는 피드백. 눈이 아닌 손끝으로 "눌렸다", "성공했다", "틀렸다"를 전합니다.

언제 쓰나결제 성공, 스위치 전환, 잘못된 비밀번호처럼 짧고 분명한 결과를 몸으로 느끼게 하고 싶을 때.

AI에게 이렇게결제가 완료되면 짧은 성공 햅틱 피드백을 주고, 실패하면 다른 패턴의 진동을 줘

20년차 메모웹에서는 기기와 브라우저에 따라 아예 동작하지 않는 일이 많으니 진동만으로 알려서는 안 됩니다. 눈으로도 같은 정보가 보여야 합니다. 너무 자주 울리면 오히려 거슬립니다.

12

알림 센터 Notification center

지나간 알림을 한곳에 모아 두고 다시 볼 수 있는 목록. 인박스(inbox)라고도 합니다. 토스트나 푸시는 놓치면 사라지지만 알림 센터에는 남습니다.

언제 쓰나알림이 많은 서비스에서, 놓친 알림을 사용자가 나중에 찾아볼 곳이 필요할 때.

AI에게 이렇게종 아이콘을 누르면 알림 센터가 열려서 읽지 않은 알림은 굵게 점과 함께 보여주고, 누르면 읽음 처리해줘

20년차 메모알림이 하나도 없을 때의 빈 화면과 "모두 읽음" 버튼을 빠뜨리는 경우가 많습니다. 알림마다 눌렀을 때 어디로 가는지도 정해 두세요. 연결이 끊긴 알림이 제일 허탈합니다.
