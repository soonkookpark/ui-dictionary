01

단계 표시 Step indicator

전체 단계 수와 지금 위치를 번호로 알려줍니다. 사용자가 해야 할 화면이 몇 개 남았는지를 말해 줍니다. 스테퍼(stepper)라고도 부릅니다.

언제 쓰나회원가입, 배송지·결제 입력, 입사 지원서처럼 여러 화면에 나뉜 신청 과정.

AI에게 이렇게지원서 작성을 4단계 단계 표시로 보여주고, 끝낸 단계는 색을 채우고 눌러서 돌아갈 수 있게 해줘

20년차 메모단계 수가 입력 내용에 따라 달라지는데 "4단계 중 1단계"로 시작하면 중간에 5단계로 늘어나 신뢰를 잃습니다. 갈라지는 길이 있다면 총 개수를 숨기고 "다음 질문"으로 가세요. 작은 화면에서는 번호만 남기고 이름은 현재 단계만 보여주는 식으로 줄여야 합니다.

프로필 완성도채울수록 올라가요

02

진행 바 Progress bar

전체 중 얼마나 했는지를 막대 길이로 보여줍니다. 여기서는 "기다린 시간"이 아니라 사용자가 채운 분량(프로필, 설문, 강의 수강)을 잽니다.

언제 쓰나프로필 완성도, 온라인 강의 수강률, 설문 응답 현황처럼 사용자의 행동으로 차오르는 목표.

AI에게 이렇게프로필 완성도를 진행 바로 보여주고, 항목을 채울 때마다 막대가 부드럽게 늘어나게 해줘

20년차 메모막대가 100%에 가까워질 때 "나머지가 뭔지"를 알려주지 않으면 사용자는 어디를 눌러야 할지 모릅니다. 막대 옆에 남은 항목 목록이나 링크를 붙이세요. 처음부터 30%쯤 채워서 시작하면 시작하는 느낌이 좋아지지만 숫자를 부풀리면 속인 느낌이 듭니다.

오늘 목표 달성

03

원형 진행 Progress ring

진행 바를 동그랗게 만 모양. 가로로 긴 자리가 없는 카드나 대시보드에서 목표 달성도를 한눈에 보여줍니다. 애플워치의 활동 링이 대표적입니다.

언제 쓰나하루 목표, 걸음 수, 학습 목표처럼 "목표 대비 지금"을 요약해서 보여주는 요약 카드.

AI에게 이렇게오늘 할 일 5개 중 완료한 개수를 가운데 숫자가 있는 원형 진행으로 보여줘

20년차 메모원은 시작과 끝 지점이 눈에 잘 안 들어와서 정확한 비교에는 막대보다 불리합니다. 여러 항목을 비교해야 하면 막대를 쓰세요. 가운데 숫자를 꼭 같이 쓰고, 색만으로 단계를 구분하지 마세요.

지원서 접수11월 3일
서류 검토11월 6일
1차 면접진행 중
최종 결과예정

04

타임라인 Timeline

세로선 위에 사건을 시간 순서로 놓은 것. 단계 표시가 앞으로 할 일을 보여준다면 타임라인은 이미 지나간 일과 지금 상태를 보여주는 데 더 강합니다.

언제 쓰나배송 추적, 채용 전형 단계, 주문 처리 이력, 환불 진행 내역.

AI에게 이렇게채용 전형을 세로 타임라인으로 보여주고 지난 단계는 채운 점, 현재 단계는 강조, 앞으로는 회색으로 표시해줘

20년차 메모각 지점에 날짜가 없으면 그냥 장식입니다. 예정일을 모르면 "미정"이라고라도 적으세요. 항목이 수십 개로 길어지면 최신 몇 개만 펼치고 나머지는 접어 두는 접기·펼치기도 설계해야 합니다.

눌러 보세요. 0/3 완료

05

체크리스트 Checklist

해야 할 일을 항목으로 나열하고 끝낸 것에 체크합니다. 진행 바가 "몇 퍼센트"라는 숫자만 준다면 체크리스트는 무엇이 남았는지를 구체적으로 알려줍니다.

언제 쓰나서비스 시작 안내(온보딩), 설정 마무리, 출시 전 점검처럼 해야 할 일이 정해져 있는 곳.

AI에게 이렇게시작하기 체크리스트를 만들고 항목을 끝내면 줄을 긋고, 위에 몇 개 완료했는지 진행 바로 보여줘

20년차 메모사용자가 직접 체크하는 항목과 시스템이 자동으로 체크하는 항목을 섞으면 혼란스럽습니다. 일을 마치면 저절로 체크되게 하고, 직접 체크하는 칸은 따로 구분하세요. 항목을 누르면 해당 화면으로 바로 이동해야 쓸모가 있습니다.

06

페이지 점 Page dots

옆으로 넘기는 화면이 모두 몇 장이고 지금 몇 번째인지 작은 점으로 알려줍니다. 캐러셀 인디케이터, 페이지 컨트롤이라고도 합니다. 정확한 숫자보다 "몇 장쯤 더 있다"는 느낌을 줍니다.

언제 쓰나앱 소개 화면(온보딩), 이미지 슬라이드, 옆으로 넘기는 배너.

AI에게 이렇게온보딩 3장 아래에 페이지 점을 넣고 현재 장만 길게 강조해줘

20년차 메모점이 8개를 넘으면 사실상 아무 정보도 못 줍니다. 그때는 "3 / 12"처럼 숫자로 바꾸세요. 점만 누를 수 있게 만들 때는 점이 너무 작아 손가락으로 못 누르니 터치 영역을 44pt 이상으로 키우거나, 넘기기 버튼을 따로 두세요.

강의 수강률

07

퍼센트 숫자 Percentage

진행 정도를 막대 없이 숫자로만 크게 보여줍니다. 모양은 단순하지만 정확한 값을 읽는 데는 막대보다 낫고, 진행 바나 링과 함께 쓰는 일이 많습니다.

언제 쓰나수강률, 달성률, 목표 대비 실적처럼 몇 퍼센트인지가 핵심 정보인 요약 화면.

AI에게 이렇게수강률을 큰 퍼센트 숫자로 보여주고, 값이 바뀔 때 숫자가 올라가는 애니메이션을 넣어줘

20년차 메모"72%"가 무엇의 72%인지(전체 강의 수인지 시간인지) 한 줄로 밝혀 주지 않으면 사람마다 다르게 읽습니다. 숫자가 바뀔 때 폭이 달라 옆 글자가 흔들리니 자릿수가 같은 숫자 서체(tabular)를 쓰세요. 숫자가 올라가는 동안 화면 낭독기가 매번 읽지 않도록 완료 후 한 번만 알려야 합니다.

문제 풀이 남은 시간

08

남은 시간 Time left

끝까지 얼마나 더 걸리는지 시간으로 알려줍니다. 카운트다운 타이머와 같은 말이 아닙니다. 타이머는 사용자에게 주어진 제한 시간이고, 남은 시간 표시는 작업이 끝나기까지의 예상입니다.

언제 쓰나시험·인증번호처럼 시간 제한이 있는 입력, 또는 "약 2분 남음"처럼 긴 업로드·설치.

AI에게 이렇게인증번호 입력 화면에 3분 카운트다운 남은 시간을 보여주고, 0이 되면 재전송 버튼을 활성화해줘

20년차 메모예상 시간을 틀리게 보여주면 안 보여주느니만 못합니다. 불확실하면 "약 1~2분"처럼 범위로 말하세요. 시간 제한이 있다면 끝나기 직전(10초)에만 색을 바꾸고, 화면 낭독기에는 1초마다 읽지 않도록 중요한 시점에만 알려 주세요.

지원서를 제출했어요 진행의 끝에는 끝났다는 표시가 필요합니다

09

완료 표시 Success state

모든 단계를 마쳤을 때 "다 됐다"고 분명하게 알려주는 상태. 진행 중 표시가 사라지고 확인 아이콘과 결과 문구로 바뀝니다. 완료 연출 자체는 따로 완료 표시 페이지에서 다룹니다.

언제 쓰나제출·결제·가입처럼 여러 단계를 끝낸 직후. 사용자가 "됐나?" 하고 불안한 마지막 순간.

AI에게 이렇게마지막 단계를 마치면 진행 바를 지우고 초록 체크와 "제출했어요" 문구, 다음 할 일 버튼을 보여줘

20년차 메모무엇이 끝났는지 한 문장으로 구체적으로 쓰세요. "성공!"만 있으면 뭐가 성공했는지 모릅니다. 그리고 완료 화면이 막다른 길이 되기 쉬우니, 다음에 할 만한 행동(내역 보기, 홈으로)을 하나는 꼭 놓아야 합니다.

캡쳐엔 없지만 알아둘 용어

실무에서 사용자의 진행 상황을 이야기할 때 함께 나오는 말들입니다.

저장 중...저장됨

10

저장 상태 표시 Autosave status

입력한 내용이 자동으로 저장되고 있는지 작게 알려주는 표시. 사용자가 진행 상황을 잃을까 하는 불안을 덜어줍니다. 구글 문서의 "저장됨"이 대표적입니다.

언제 쓰나긴 글쓰기, 설문, 지원서처럼 사용자가 오래 입력하는 폼.

AI에게 이렇게입력을 멈추고 2초 뒤에 자동 저장하고, 위에 "저장 중..." 다음 "저장됨"을 보여줘

20년차 메모저장에 실패했을 때의 문구가 가장 중요한데 거의 그려지지 않습니다. 인터넷이 끊기면 "저장 안 됨, 연결되면 다시 시도할게요"를 보여주지 않으면 사용자는 날아간 글을 모르고 나갑니다.

작성 중인 지원서 3/5단계 · 어제 저장

11

이어하기 Resume

중간에 나갔다가 돌아온 사용자를 멈춘 지점부터 다시 시작하게 해주는 기능. 진행 표시가 있어도 이어하기가 없으면 처음부터 다시 해야 합니다.

언제 쓰나단계가 많은 신청서, 긴 강의, 오래 걸리는 설정 마법사.

AI에게 이렇게작성하다 나간 지원서는 홈 화면에 이어하기 카드로 보여주고, 누르면 마지막 단계로 이동해줘

20년차 메모어제 저장한 내용이 오늘의 정보와 달라졌을 수 있습니다(재고, 가격, 마감). 이어하기 후 첫 화면에서 바뀐 점을 확인시키세요. 그리고 "처음부터 다시 하기"도 가까이에 있어야 합니다.

알림을 켤까요? 나중에 할게요

12

건너뛰기 Skip

진행 과정의 필수가 아닌 단계를 넘기게 해주는 선택지. 보통 눈에 덜 띄는 글자 링크로 두어, 주 버튼과 구분합니다.

언제 쓰나온보딩, 프로필 꾸미기, 알림 권한처럼 없어도 서비스를 쓸 수 있는 단계.

AI에게 이렇게온보딩 각 단계 아래에 "나중에 할게요" 건너뛰기 링크를 작게 넣고, 건너뛴 단계는 체크리스트에 남겨줘

20년차 메모건너뛰기를 숨기면 사용자가 서비스를 떠납니다. 반대로 필수 단계(본인 인증 등)에 넣으면 나중에 문제가 생깁니다. 건너뛴 일을 다시 할 곳이 있는지가 핵심입니다.
