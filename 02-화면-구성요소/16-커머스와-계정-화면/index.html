상품 카드 Product card · PLP card

목록 안에서 상품 하나를 사진·이름·가격·찜 버튼으로 요약한 카드입니다. 상품 목록(PLP)에 반복해서 놓이는 가장 작은 단위라서 PLP 카드라고도 합니다.

언제 쓰나쇼핑몰 목록, 검색 결과, 추천 상품 줄처럼 상품이 여러 개 나열되는 곳.

AI에게 이렇게상품 목록에 쓸 상품 카드를 만들어줘. 사진, 브랜드, 이름, 할인율과 가격, 찜 하트를 넣고 카드 전체를 누르면 상세로 가게 해줘

실무 팁카드에 정보를 많이 넣을수록 비교가 어려워집니다. 사진, 이름, 가격 세 가지가 먼저 읽히게 하고 나머지는 작게 두세요. 이름이 두 줄을 넘는 경우, 이미지가 늦게 뜨는 경우, 품절 표시가 붙는 경우까지 한 카드 안에서 미리 설계해야 합니다.

상품 목록 PLP · Product listing page

카테고리나 검색 결과에서 상품 카드를 격자로 늘어놓은 화면을 PLP(Product Listing Page)라고 부릅니다. 상품 하나를 자세히 보여주는 상세 페이지(PDP)와 짝을 이룹니다.

언제 쓰나카테고리 화면, 검색 결과, 기획전처럼 여러 상품 중에서 고르는 단계.

실무 팁목록에서 가장 중요한 건 필터와 정렬이 상태를 기억하는 것입니다. 상세에 들어갔다가 뒤로 오면 스크롤 위치와 필터가 그대로여야 합니다. 결과가 0개일 때, 로딩 중일 때, 한 줄에 몇 개를 보여줄지(폰 2열, 데스크톱 4열)도 정해두세요.

상품 상세 PDP · Product detail page

상품 하나의 사진, 가격, 옵션, 설명, 리뷰를 한 화면에 모은 페이지입니다. 이름은 PDP(Product Detail Page)이고, 구매 결정이 일어나는 가장 중요한 화면입니다.

언제 쓰나목록에서 상품을 눌러 들어온 뒤, 담기·구매를 결정하는 단계.

AI에게 이렇게상품 상세 화면(PDP)을 만들어줘. 위에 사진 슬라이드, 아래에 이름·가격·옵션, 하단에 고정된 장바구니·구매 버튼을 두고 그 밑에 설명과 리뷰 탭을 넣어줘

실무 팁구매 버튼이 스크롤하면 사라지는 상세 화면이 의외로 많습니다. 폰에서는 하단 고정 바로 항상 보이게 하세요. 옵션을 안 고르고 눌렀을 때의 안내, 품절 옵션, 사진이 안 뜰 때가 빠지기 쉬운 상태입니다.

최종 금액이 어떻게 나왔는지 소계·배송비·할인·합계로 풀어 보여주는 표입니다. 할인은 빼기(-) 표시와 다른 색을 쓰고 합계를 가장 크게 둡니다. 합계 한 줄만 보여주는 것과 달리 근거를 줍니다.

언제 쓰나장바구니, 주문 요약, 영수증처럼 돈이 확정되는 모든 곳.

실무 팁결제 직전에야 배송비나 수수료가 나타나는 건 가장 큰 이탈 원인으로 꼽힙니다. 확정되지 않은 값은 "주소 입력 후 계산"처럼 이유를 밝히세요. 숫자는 자리가 흔들리지 않게 오른쪽 정렬과 고정폭 숫자를 쓰는 게 좋습니다.

09

프로모션 코드 입력 Promo code field

할인 코드를 적고 적용하는 칸입니다. 결과를 바로 "적용됨"이나 오류로 알려주고, 적용되면 가격 분해에 할인이 반영됩니다. 쿠폰 목록에서 고르는 방식과 달리 직접 입력합니다.

언제 쓰나체크아웃 단계, 이벤트 코드나 지인 추천 코드를 받은 사용자.

AI에게 이렇게주문 화면에 프로모션 코드 입력 칸과 적용 버튼을 넣고, 유효하면 초록 확인과 할인 금액을, 아니면 이유가 적힌 오류를 보여줘

실무 팁코드 칸을 크게 눈에 띄게 두면 코드가 없는 사람이 "어디서 찾지" 하다 나가버립니다. 접어서 "코드가 있나요?" 링크 뒤에 두세요. 오류는 만료, 이미 사용, 최소 금액 미달처럼 이유를 나눠 알려야 하고, 대소문자 구분은 하지 않는 편이 안전합니다.
